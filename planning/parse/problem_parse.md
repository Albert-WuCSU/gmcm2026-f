## 1. 题目背景

以「培养一名高质量学生」类比大模型训练，给出五个量：参数量 **N**（脑容量）、训练数据量 **D**（阅读量）、
计算量 **C**（教育经费）、数据质量 **Q**（教材质量）、领域配比 **p**（各科课时分配）。

经典标度律只刻画 N、D 与验证集交叉熵损失的关系：

$$L(N,D) = E + A\,N^{-\alpha} + B\,D^{-\beta}$$

其中 E 为不可约损失，A、α、B、β 为待估参数。全文 Loss 均指**验证集交叉熵损失**。
模型能力还通过下游多维评测基准（Benchmarks）衡量，二者**相关但不等价**。

在高质量语料稀缺、数据污染加剧的「数据墙」背景下，Q 与 p 对模型能力有不可忽视的作用
（赛题引 Nature 2026：80 亿参数的 OpenScholar-8B 在引文准确率、降低幻觉等任务上优于 GPT-4o）。
扩大 N、提升 Q、延长上下文长度 L_ctx 均消耗算力；调整 p 不增加算力总开销，但改变算力在各领域的分配效果。
四者存在取舍。

## 2. 总目标

在给定算力预算下，建立 N、D、Q、p 与 Loss 之间的定量关系，据此求解资源配置最优方案，
并用历史评测数据检验规律、预测开源模型能力前沿。

## 6. 题目已给定的闭式与参数（不可自行改动）

- 基础训练开销 `C_train = 6ND`（Chinchilla 近似）
- 质量提升开销 `C_Q = D·[g(Q) − g(Q₀)]₊`
- 长文本注意力开销 `C_attn = η·N·D·L_ctx`，**η = 2×10⁻⁴**
- 注意力与训练开销相当的临界值 **`L_ctx^crit = 6/η = 30000`**（题目要求解析给出）
- 三类成本函数（附录 B.1）：指数型 `g=γe^{λQ}`（γ=1e7, λ=6.0）；幂函数型 `g=γQ^λ`（γ=5e9, λ=4.0）；
  对数渐进型 `g=γln(1+λQ)`（γ=2e9, λ=10.0）
- 建议预算档位：C = 10¹⁹、10²²、10²⁴ FLOPs（可另选，但须至少三个不同量级）

注：C7 实测可行 L_ctx 中，**32768 与 131072 两档超过临界值 30000**，敏感性分析须覆盖跨临界情形。

## 8. 风险点

数据完整性风险已在第 0 节处理。建模侧主要风险：

- **跨体系映射误差**：A16 自带 `direct/near_direct/inferred` 三级可信度，c4 域无对应配方列，
  Q 引入配比模型必然携带假设，需敏感性分析。
- **四域无 Loss 列**：`nih_exporter`、`philpapers`、`enron_emails`、`europarl` 的处理方式影响 Q1c 因变量口径。
- **半合成数据承重过度**：B6–B8 是唯一含 Q 的数据，而 Q 是 Q2、Q3 的核心自变量。
  若把半合成点当作主拟合证据，结论可信度会被高估，须显式限定其角色。
- **外推链条累积**：Q3 高预算档（10²⁴）依赖 Q2 标度律外推，而 Q2 的百亿以上部分又依赖 B9/B10（估算值）。
- **误差逐问传递**：Q1 的 Q 误差 → Q2 参数 → Q3 最优解 → 与 Q4 印证，需在各问交界处报告不确定性。
