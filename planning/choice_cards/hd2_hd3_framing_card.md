# HD-2：四问成功标准

两套方案的差别不在"严不严"，而在**成功由什么定义**：绝对门槛，还是相对 baseline 的改进。

## 方案 A：绝对门槛制

现在就为每问定下固定数值门槛，达标即通过，未达标触发 fallback。

| 子问题 | 交付形式 | 检验方式 | 门槛 |
| --- | --- | --- | --- |
| Q1a 质量评价 | 7 域的域级 Q（抽样集 vs 扩展集两套） | 权重法敏感性 + 抽样/扩展一致性 | 换权重方案后域排序 Spearman ρ ≥ 0.8；抽样集与扩展集同域 Q 差值 ≤ 0.1（Q 归一到 [0,1]） |
| Q1b 冲突消解 | 冲突定义 + 冲突率 + 成因 + 消解后评分 | 抽样集全覆盖，扩展集复核 | 冲突率落在 (0%, 100%) 开区间且给出量纲依据；消解前后域排序变化可解释 |
| Q1c 配比建模 | 17 维 p → Loss 模型 | A6–A11 三尺度分别报告 | 每个尺度 out-of-sample R² ≥ 0.7，或相对误差中位数 ≤ 5% |
| Q2 广义标度律 | L(N,D,Q,p) 解析式 + 参数 + 弹性 | B1 拟合 / B2或B3 轨迹 / B4+B5 跨族 | B1 上 R² ≥ 0.9；跨族验证相对误差中位数 ≤ 15%；**弹性符号必须 ∂L/∂N<0、∂L/∂D<0、∂L/∂Q<0** |
| Q3 优化 | 三档预算的 (N\*,D\*,Q\*,p\*) + 结构转移判定 | KKT 残差 + 预算占用 + 三种 g(Q) 对比 | 最优解满足 KKT（残差 ≤ 1e-6）；预算占用 ∈ [99%, 100%]；`L_ctx^crit=30000` 解析给出并跨临界做敏感性 |
| Q4 演进与前沿 | 贡献占比 + 12/24 月前沿区间 | 时间外样本回测 + 桥接分层 | 留出最后 6 个月做回测，实际值落在预测区间内；桥接映射 **Loss 与 Benchmark 必须负相关**；C8 至少一项逐任务聚合 |

**利**
- 判据明确，我可以长时间自主迭代不必反复问你；每轮自己就能判断"过了没有"。
- 论文里"模型充分性"一节有硬证据可写。
- 符号检查（弹性为负、桥接负相关）能自动拦住方向性错误——正好是隐藏文本试图植入的那类错误。

**弊**
- 门槛数值是我在**尚未拟合任何模型**时提的，可能偏松或偏紧。特别是 Q1c 的 R²≥0.7：RegMix 类配比→Loss 回归的真实可达精度我还没测过，这个数字有被推翻的风险。
- 达不到门槛时容易诱发"调参凑指标"，而不是去质疑模型形式。
- 门槛一旦写进论文，中途改动需要解释。

**触发条件**：任一门槛连续两轮未达到 → 回到 method-selector 重新筛方法，而不是继续调参。

## 方案 B：相对 baseline 制

不预设绝对数值。每问先跑一个**明确定义的简单 baseline**，主方法必须在预先声明的指标上超过它，
且超出幅度大于数据噪声水平。

| 子问题 | baseline | 主方法须证明 |
| --- | --- | --- |
| Q1a | 22 指标方向统一后**等权平均** | 优于等权：域排序更稳（重抽样下方差更小），或能解释等权无法解释的冲突结构 |
| Q1b | 无消解，直接等权 | 消解后评分在扩展集上的跨域一致性优于未消解 |
| Q1c | 17 维 p 的**线性回归**（带单纯形约束） | 三个检验尺度上均优于线性 baseline，且优势超过尺度间波动 |
| Q2 | **经典标度律** L=E+AN^−α+BD^−β（不含 Q、p） | 加入 Q、p 后在含 Q 数据上显著改进，且 Q→1 时行为与经典式一致 |
| Q3 | **Chinchilla 经验配置**（N∝D，忽略 Q 与 attn 开销） | 联合优化解的 Loss 低于 Chinchilla 配置，且能给出结构转移的可识别证据 |
| Q4 | **纯时间趋势外推**（不分解规模/技术） | 分解模型的回测误差低于纯趋势外推；贡献占比估计带不确定性区间 |

**利**
- 门槛自适应数据真实难度，不会因为我猜错数字而误判。
- 直接满足 AGENTS.md 的 `usable_baseline` 要求——baseline 本来就必须实现，这里让它同时承担判据。
- 论文的对比章节天然成形："我们的方法相对经典标度律/Chinchilla 改进了多少"，比"R²=0.9"更有说服力。
- 更难自欺：baseline 是同数据同口径跑出来的。

**弊**
- baseline 若本身很强（如经典标度律在 B1 上可能已经拟合得很好），主方法的增量可能很小，
  届时需要你判断"小改进是否值得"——**会多一次决策往返**。
- 计算量约增加 40%（每问多跑一套完整 baseline）。
- "显著改进"仍需定义显著性口径（我会用重抽样置信区间，这是机械可判的，不需要你决定）。

**触发条件**：主方法在两轮内无法超过 baseline → 承认 baseline 更优并如实写入论文，或重新筛方法。

# HD-3：范围与实验预算

## 方案 A：最低必用集优先

只做赛题附录 A 与《强制使用清单》标明必用的数据，**先把四问链条完整跑通**，可选项留到稳健性阶段再看。

**纳入**：A1–A17（含全量 A1/A2/A3）、B1–B10、C1–C8（含 C8 全量逐任务聚合）
**暂不纳入**：A18（165 MB RegMix 原文）、C9（parquet，与 C1 六维等价）、C10（仅 README）、B11/B12 仅按需查元数据

**关于"用原文检验评分是否可靠"**：题目问题一的通俗理解要求"用原始教材内容检验评分是否可靠"。
实测 **A1 自带 `content` 字段**，可直接在质量信号侧做文本级抽查，**不必解压 A18**。
A18 属于 RegMix 侧文本（域体系与质量信号侧不同），是另一条独立的校验路径。

**利**
- 最快形成端到端闭环，Q1→Q2→Q3→Q4 全链条先跑通，早暴露跨问接口问题（尤其 Q1 的 Q 与 B6–B8 的 `Q_score` 是否同尺度——这是目前最可能出问题的接口）。
- 必用集实测很便宜：A1–A3 全量约 10 秒；主要成本是 C8 的 1958 个 JSON。
- 合规充分——必用清单全覆盖。

**弊**
- 文本级校验只有质量信号侧一条路径（A1 的 `content`），RegMix 侧无独立文本证据。
  若评审关注"跨体系映射是否可靠"，证据链会略薄。
- A17 标注为"本版未接入求解，供扩展分析"，方案 A 只做基本接入，不展开域摘要的深度分析。

---

## 方案 B：必用集 + A18 原文校验

在方案 A 基础上，增加 A18 的**抽样**使用（不是全量 138034 条）：按 17 个 RegMix 域各抽若干文档，
计算与质量指标可比的文本统计量，用于独立检验跨体系域映射（A16）的合理性。

**利**
- 跨体系映射（7 质量域 ↔ 17 配方域）获得**独立文本证据**，而不只依赖 A16 的人工整理表。
  这正好补上我在解析阶段标记的最大风险之一。
- 问题一"检验评分是否可靠"有两条独立路径，论文的验证章节更厚实。
- A18 的域分布可与 A17 域摘要交叉核对。

**弊**
- 额外解压与统计成本：165 MB xz，抽样处理预计数分钟到十几分钟（取决于抽样率），比方案 A 多一个处理环节。
- 引入新的口径问题：A18 的文本统计量与 A1 的 22 个质量指标**不同源**（前者是我算的，后者是数据集自带的
  模型打分），两者只能做趋势一致性对照，不能直接数值比较。这个局限必须写进论文。
- 若时间紧张，这部分是最容易被牺牲的，届时已投入的工作可能白费。
