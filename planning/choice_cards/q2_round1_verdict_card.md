## 裁定 3：`claim_scope`

### 事实

**这是本问唯一需要你定口径的地方，其余都已机械判定。**

**(a) `gamma` 与它的解释边界。**
`gamma` = **0.9659128363851796**，CI95 **[0.8838599505464407, 1.055546203294626]** **含 1.0**。
`γ ≈ 1` 时 `D_eff = D·Q^γ` 即 `D_eff ≈ D·Q`，可读作「**质量按比例放大有效 token 数**」。

**但有两个硬边界**：

1. **`gamma` 完全由半合成 B7 决定**（B1 上 `Q=1`，对 `gamma` 零信息）。
   按 GC5 须披露，该结论带「补充分析」属性。
2. **AMB-Q2-3 尺度对齐未解决**：Q1 经验域级 Q 落在 **[0.223306, 0.381496]**，
   而 B7 设计网格 Q 是 **[0.1, 0.2, …, 1.0]** —— **不是同类对象**。
   本轮**明确不做静默映射**（账本原文）⇒ `gamma` 的解释**绑定在 B7 的设计刻度上**。
   **直接说「数据质量 Q 每提高 1 单位使有效 token 数翻倍」会越界到 Q1 的刻度。**

**(b) `Q + 0.1` 等价 `N` 增量**（题目直接要求的量）：
参照点 `N` = 1.0B、`D` = 150.0B、`Q` = 0.5 下，B1 侧 **−0.13410087180720998**、
B7 侧 **−0.09446921433033195**（负 = 提质可减少参数量）。
**两侧量级差**：全部五个含 `gamma` 的量相对差 **15.0%–31.8%**，该差即「跨源统一假设的代价」。

**(c) `kappa`**：严格不可辨识（B 侧 RMSE 随其变化 = **0.0**）。
敏感性臂给 `kappa` = **−14.215132486372847**（参照点 `D_tokens_B` = 299.893），
但 **`kappa` 随参照点变**（B1 的 1B run 内 −14.2151 到 −1.6413，差 **8.7 倍**）⇒ **无普适值**。

**(d) 域比值表**：17 个域相对 `train_the_pile_philpapers` 的比值，
CSV 自带 note 声明为「**中心化 `w` 之比，非有界比例**」；全表**仅** `dm_mathematics` 的 `abs_gt_1` = yes（−1.618816）。

### 选项

**A. 主张「在 B7 设计刻度上 `D_eff ≈ D·Q`」，并把三条硬边界写进正文。**

- 可主张：`gamma` 区间含 1.0；在该设计刻度上质量按比例放大有效 token 数；
  `Q+0.1` 等价 `N` 增量（带参照点、两侧同报）；`kappa` 只报方向与域间排序、不报绝对量级。
- 代价：须在正文写明「半合成」「刻度未对齐」，并**不得**把结论移植到 Q1 的经验 Q 上。

**B. 更保守：只报 `gamma` 及其区间，把 `D_eff ≈ D·Q` 列为「与数据相容的解释」而不作主张。**

- 收益：全部论点只依赖「区间含 1.0」这一件事，不依赖对 `gamma` 的实质解释。
- 代价：Q2 最有价值的结构性结论退化为一句观察；Q3 若要用 `D_eff` 形式，须自行论证。

**C. 更进取：主张该比例放大关系**跨刻度**成立（即也适用于 Q1 的经验 Q）。**

- **当前无证据支持**：AMB-Q2-3 的对齐规则未建立，本轮未做任何映射。
  选 C 须先补做刻度对齐（把 Q1 域级 Q 与 B7 设计刻度建立显式映射并声明假设），
  这是一项新工作，且对齐规则本身属建模判断（须你定）。
- 收益（若补做成立）：结论强度最高。
- 代价：新增工作 + 一处新的承重假设。

**(e) 另有一条独立的小口径选择**（可与上面任一选项并存）：
域比值表可作「哪些域 upweight 会降 Loss」的**排序**报出，但须带「中心化 `w` 之比、非有界比例」的语义声明；
或只报「Loss 最高/最低两个域」而不列全表。请在答复中一并说明取哪种。
