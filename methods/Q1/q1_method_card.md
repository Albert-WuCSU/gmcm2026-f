## Shortlist

Q1 含**两个数学上不可合并的估计问题**：质量侧为无监督多指标合成（无目标变量），
配比侧为有监督回归（有目标变量与独立检验集）。二者各配恰一个主方法与一个 baseline，
共享一个 fallback。**非为凑候选数量**（HD-2 本身亦分别声明了 Q1a/Q1b/Q1c 的 baseline）。

| ID | Role | 数学思想 | 入选依据 | 主要风险 | 实现成本 |
| --- | --- | --- | --- | --- | --- |
| **M1** | main（质量侧） | 语义分组 V/P + 门控合成 `Q = V·(1−P)`；冲突 = 高价值 ∧ 高污染（分位数锚定） | 门控式恒在 [0,1]，与 Q3 的 `g(Q)=γQ^4`、`γe^{6Q}` 相容；组间近零相关使冲突非空 | V/P 分组无相关内聚性，只能以语义论证 | 低 |

| **M0c** | baseline（配比侧） | 17 维 p 线性回归（去截距或指定参照域），目标为配比加权 13 域 Loss | HD-2 指定；系数 100% 符号稳定，跨尺度去偏 R² 0.705–0.771 | 无法刻画域组合效应 | 低 |

### 承重发现（按影响排序）

1. **方向表内部矛盾（FAIL）**：22 指标统一为「越高越好」后，仍有 **20 对相关系数 < −0.5、10 对 < −0.8**，
   其中 **17 对涉及 Tier C**。最严重者 `dsir_math ~ rps_doc_word_count = −0.935`——二者都被标为正向，
   却强烈反向，至少一方的方向赋值与数据不相容。
2. **Tier C 方向决定域级 Q 排序**：`book` 在五种方向假设下分别位列第 **5 / 2 / 7 / 2 / 5** 位，
   **跨度 5 个名次**（7 域中），单次变更的最大名次位移为 3；Spearman 最低降至 0.625。
   `c4` 同样从第 2 位摆到第 1 或第 5 位。而 `mean_word_length` 的处理方式几乎无影响
   （Spearman 0.998、名次位移 0）——6 个 Tier C 中 **5 个承重、1 个不承重**。
3. **归一化口径两难**：按域 ECDF 可把 Q 的域标签信息降到 AUC 0.498，但域间极差同时降到 **0.0028**
   （域级 Q 近乎恒等，与 Q1a 必交产出冲突）；合并或以 A1 为参照时 AUC 达 0.98–0.99，Q 近乎等价于域标签。
4. **GC2 字面 Min-Max 数值退化（FAIL）**：`word_count` 中位数落在量程的 **0.027%** 处，
   `dsir_*` 落在 **99.88%** 处。须先截尾或改用经验分位数。GC2 的硬性要求是「统一为越高越好」，
   补转换公式在原文中是「例如」引出的示例。
5. **Q1c 跨尺度误差几乎全是水平偏移**：60m/1B 的原始 R² 为 −8.4 / −173，但 **bias 占 RMSE 的 98.8% / 99.9%**；
   去掉按尺度常数后 R² 回到 0.771 / 0.705，Spearman 0.922 / 0.887。
   **即配比→Loss 的形状跨尺度可迁移，只有水平随规模平移** —— A6–A11 的验证口径必须含按尺度截距或改用秩相关。
6. **A12–A15 只能检验 Loss 外推**：A12/A14 的配比行与训练集 **完全重复**（重复率 1.0），
   不能检验配比泛化；且去偏后 R² 仍为负（−0.66 / −1.22），说明幂律外推未保持配比响应形状，只能定性讨论（GC5）。
7. **`book` 与 `wikipedia` 的域级 Q 不可区分**：二者相差 0.0045，而 `book` 的 bootstrap 半宽为 0.0077
   （区间宽度为 `github` 的 **29.6 倍**，n=171 vs 213 751）。

### 已据证据排除（非凑广度，均有可核验反证）

| 候选 | 排除理由 |
| --- | --- |
| 熵权法 / 熵权-TOPSIS 族 | 权重离散度完全由归一化方案决定：分位数下退化为等权（max/equal = **1.002**，零增量）；截尾 Min-Max 下 **58% 权重压在 3 列**，其中 2 列恰是方向未定且域指示性最强的长度类指标 |

| 平方根变换主效应回归 | 训练 R² = **−2.78** |
| ILR 等对数比变换 | 512 行中 511 行含精确零，每行中位 8/17 域为零（沿用数据阶段结论） |

## 已固化的机械结论（不需人工裁定）

- **8 个列表型字段标量化规则**（沿用 F1）：`fineweb_edu` 直接取值；`ad_en`/`fluency_en` 取 logit 差
  `pos1−pos0`；4 个 `modernbert_*` 取 softmax 期望类别；`qurater` 4 准则等权合为 1 列（保持题目 22 指标计数）。
- **`ad_en` 与 `fluency_en` 的极性已由原文核验定案**：`margin = pos1 − pos0` 度量的是
  **「不像广告」与「流畅」**，本身已是越高越好，**不需补转换**。
  证据：`ad_en` margin 最低 6 条全为广告文案（音箱促销、度假村推销、空调商家、路由器带货、赞助招商、床垫大促），
  最高端为论坛讨论与新闻；`fluency_en` 最低端为 SEO 垃圾与机翻乱码，最高端为通顺散文。
  → 若按字面把 `ad_en` 当「广告含量」做 `1−x`，符号会反。证据存于 `workspace/data/q1_polarity_evidence.json`。
- **`dsir_*` 是按 token 求和的对数似然比，被文档长度主导**（G2 补充探针，2026-09-24 晚）：
  `log(−dsir) ~ log(word_count)` 的 Pearson 达 **0.937–0.939**，与 `word_count` 的 Spearman 为 −0.93。
  逐 token 归一化（除以词数）后：与 `fineweb_edu` 的 Spearman 从 **−0.499 翻正到 +0.374**；
  `dsir_books` 的域序从「`book` 排第 7」变为「`book` 排第 1」，AUC(arxiv:github) 从 0.034 变 0.946。
  → **原始字段的表观方向是长度效应的产物**，`book` 在「书籍相似度」上排最后即是其不可直接使用的反证。
  证据：`workspace/data/q1_probe_dsir_length.json`。
- **`dsir_books/wiki/math` 互相关 r = 0.999（逐 token 后仍 0.996）**，实质是 1 个指标，须合为代表量。
- **待使用者确认的重新分层**：若采纳逐 token 归一化，`dsir` 的方向依据由「建模判断」升级为
  「数据可证」，可由 Tier C 降为 Tier B，人工裁定范围随之只剩 3 个长度类指标。
- **配比回归须显式去截距或指定参照域**：`Σp = 1` 下截距仅靠千分位舍入（最大偏离 0.004）可辨识，
  条件数 61 → 4773（×78），该系数无实质解释。
- **`M1c` 的单个二阶交互系数不可解释为域间替代/互补**（符号稳定率仅 0.549，平均相对标准误 1.514）。

## 论文须披露的局限

1. A18 文本统计量由本队自算，A1–A3 的 22 指标是数据集自带的模型打分，两者不同源，
   只能作趋势/秩一致性对照，绝对值不可比（HD-3 承诺项）。
2. `book` 域仅 171 条，其域级 Q 与 `wikipedia` 在统计上不可区分。
3. A12–A15 为外推/子集，仅支持定性讨论，不得表述为直接实验观测（GC5）。
4. **《数据说明》并未给出 22 指标的方向标注**，尽管赛题附录 B.2 指向该处。本队的方向表由指标语义
   与公开过滤器口径（RedPajama-v2 / Gopher / C4）推得，并按三层可信度标注（A 8 项 / B 8 项 / C 6 项），
   承重的 Tier C 项由本队裁定并报敏感性。
5. **`rps_doc_frac_unique_words` 与 `rps_doc_unigram_entropy` 这一对受长度反向混淆**
   （对 `log(word_count)` 的 Spearman 分别为 **−0.85 与 +0.95**）。**须写成「这一对」，不得只点
   `frac_unique_words`** —— `unigram_entropy` 才是更大的长度载体。canonical 保留的 3 对
   r<−0.5 弱矛盾全部牵涉该对，已判定为**长度诱导的伪矛盾而非语义冲突**：纯长度即可生成
   约 −0.81 的负相关，而双方各自去长度后相关为 **+0.92 强一致**，即在同一长度下二者测的是
   同一构念（词汇多样性）。决策 `q1_frac_unique_words_treatment = no_treatment`，
   规格未改。证据：`workspace/data/q1_probe_unique_words_length.json`。
6. **canonical 的 Q 本身带长度暴露**：`corr(Q, log word_count)` 的 Spearman 为 **0.499**。
   这是这 22 个指标普遍受长度混淆的结果，非本规格新引入，与「单一标量 Q 不可能同时做到
   跨域可比与域去混淆」同源。
