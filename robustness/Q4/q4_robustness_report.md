### 2.3 规模通道与 0 不可区分（C3）—— PASS

这是 Q4 最需要谨慎的一条，因为**两种不确定性来源给出相反的印象**：

| 不确定性来源 | `scale_share` 区间 | 含 0？ |
| --- | --- | --- |
| round1 自助（只重抽**模型**，B=2000，主口径 A） | [0.0223, 0.4019] | **否** |
| round2 趋势法自助（按月分层重抽，B=1000，用全部 10 个月） | [−0.1942, +0.2258] | **是** |
| round2 端点定义（重抽**末端**定义，非自助） | 四点：+0.2593 / +0.1811 / −0.0282 / +0.2205 | 跨 0，**符号翻转** |

**判读**：round1 的区间未覆盖端点选择，故其不含 0 不构成「规模贡献显著为正」的证据；
端点极差 **0.2875** 本身已大于主口径点值（0.2593），且含一次符号翻转。
趋势法（不取两端点、用全部 10 个月斜率）是唯一同时覆盖月间变异与模型变异的口径，
其区间含 0。**三源合读支持「与 0 不可区分」。**

`M2a`（改报绝对点数）的触发判据是「所采用 f(N) 规格下 `scale_share` 自助 95% 区间下界 < 0」。
主口径 A 下未触发（下界 0.0223）；若改采规格 B 则触发（点值 −0.2827 < 0）。
按裁定 `q4_fn_spec_and_method_choice = C_main_spec_A`，A 为主口径 ⇒ **fallback 保持休眠**，
但规格 B 的负份额**必须一并报告**（裁定 C 的明文约定）。

| **裕度** | **1.881** |
| 中性 h12 中位数 | 56.33 |

> 首轮实现把 **均值层面**的 `tau` 月斜率（0.4675）直接加到 **q90 前沿**水平上，
> 对象不一致，系统性低估（q90 自身斜率 1.5333）。首轮结果 `lo80 = 32.276 < 41.387` ⇒ **判据 FAIL**。

> 论文与本节须如实写这一次序，并注明裕度仅 1.881 点。
> 来源：`code/Q4/reviews/q4_python_review.json#findings[F-Q4-3]`。

95% 宽度如实报告（41.935，约为当前前沿 41.387 的一倍）**但不作闸门** —— 这是判据的原文约定。

### 3.2 预测维度对 baseline 的对照（C7）—— **FAIL（主方法未打赢）**

HD-2 为「相对 baseline 制」。方法卡明文要求：归因维度上 baseline 结构性不能分解（定义性胜出），
但**预测维度上主方法须真打赢它，不得回避比较**。同口径（h12，q90 前沿）对照：

| 量 | M1a（主，中性情景） | M0a（baseline，纯趋势） |
| --- | --- | --- |
| h12 点/中位 | **56.33** | **60.29** |
| 80% 区间 | [43.268, 69.699] | [56.448, 64.131] |
| 95% 区间 | [35.513, 77.449] | [54.415, 66.165] |
| 95% 宽度 | **41.935** | **11.750** |
| 斜率 | 按份额拆通道（1.1358 技术 + 0.3975 规模） | 1.5333/月 |

**结论（不得回避）**：预测维度上，**主方法点值比 baseline 低约 6.6%，区间宽约 3.6 倍**；
且预声明的预测判据（§3.1）**baseline 也满足**（其 `lo80 = 56.448 > 41.387`）。
⇒ 预声明预测判据上主方法**不构成对 baseline 的优势**。

**这不推翻 Q4 的主 claim** —— 按 `q4_primary_defense_target = A`，Q4 的主 claim 是**归因**，
预测为「照常交付但不作主 claim」。但论文在呈现预测表时**必须同表列出 baseline**，
并说明：主方法的价值在于给出**可分解的、带情景结构的**区间，其代价是区间更宽、
点值更低（因情景参数对技术趋势施加了衰减，而纯趋势外推不衰减）。
**不得只报主方法的中位数而隐去 baseline 的 60.29。** 此项登记为论文措辞待办。

### 3.3 不确定性与误差传播

蒙特卡洛同时抽取三类来源：技术趋势斜率、桥接映射误差（`mapping_error_sigma = 10.1726`）、
桥接斜率不确定性（`slope = −22.393`，CI95 `[−44.481, −7.8308]`）。
桥接 rmse **10.9842** —— 与得分尺度同量级，是 95% 区间偏宽的主因。
**这是诚实的不确定性，不是缺陷**：9.1 个月窗口 + n=75 的桥接样本只能给出这个精度。

### 3.4 24 个月视界

**不作主报**（`q4_horizon_scope`）。理由：乐观 h24 中位 **94.118** 逼近 0–100 上界，
其 95% 宽度 **29.236** 反而**窄于** h12 的 41.184 —— 这是截断到 100 造成的假象，不是精度提高。
得分上界的**饱和形态在 9.1 个月窗口内不可检验**。若列出 h24，须显式声明该假设不可验证。

## 5. 甲/乙规模通道定义的偏误（C10）

`F-Q4-2`（high，曾为 G4 阻塞项）已由人工裁定处置。

**原登记断言**（`q4_scale_channel_definition.binding_commitments.known_bias_direction`）：
「甲单独使用时对技术进步占比为系统性高估」。

**本轮实测（66 子集）**：甲 `tech_points = −1.4083` vs 乙 `−1.1631`，
差 **−0.2451**；`scale_points` 差 **+0.2451**（精确抵消）。
但该子集 `total_points = −4.5487`（**负**）⇒ `share` 与 `points` 的比较必然反向，
**两者都不构成偏误方向的证据**。

**处置（人工裁定 `q4_scale_channel_bias_direction_correction`）**：
撤回实证方向断言，保留机制断言。现行表述为
「省略 compute 会在规模通道与技术通道之间**重分配**解释力，净效应的方向**随样本而定**，
不是固定的高估。在 66 子集上重分配量为 **0.2451** 点（精确抵消）」。

**机制成立、方向不成立**的分界必须写清。另记（HANDOFF 已核）：66 子集末期 `2025Q1`
仅 3 个模型、中位 `logN` 掉到 0.180、`S_mean` 掉到 7.765 ⇒ total 为负是**端点抽样假象**。
该子集 pretrained 占比远高于全样本，**不是同一总体**，偏误只给符号与量级，
**不得作全样本修正系数，不得表述为「已校正」**。
